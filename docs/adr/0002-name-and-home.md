# ADR-0002: Name and home

Status: accepted, 2026-10-15.

## Decision

The product is called **Semascope** (sema, a sign or meaning; scope, an
instrument for seeing) and lives at github.com/rdb420/semascope. On
2026-10-15 the name was free on PyPI, npm and GitHub.

## Context

"Open Semantic Search" belongs to its author and to opensemanticsearch.org.
Reusing it for a different codebase under a different licence would mislead
users and search engines.

## Consequences

Python packages are prefixed `oss-` (the working abbreviation from the
planning phase) and the command is `oss`; the product name in prose and UI is
Semascope. Images are published as `ghcr.io/rdb420/semascope`.
