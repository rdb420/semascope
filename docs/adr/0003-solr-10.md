# ADR-0003: Apache Solr 10 as the search engine

Status: accepted, 2026-10-15.

## Decision

Semascope ships with Apache Solr 10.x (10.0.0 released 2026-03-03, Java 21).
The index layer sits behind the `IndexBackend` protocol so a contributor can
add another engine, but 1.0 supports Solr only.

## Context

Solr's Tagger handler tags documents and queries against a dictionary of up
to hundreds of millions of names with FST speed, in the engine, which makes
re-tagging after a vocabulary change cheap. It is present in the Solr 10
guide. Solr 10 also carries `DenseVectorField` with quantisation and the `knn`
parser for semantic search, the JSON Facet API for hierarchical facets, and an
FST suggester. A single node runs in a gigabyte of heap.

## Alternatives

OpenSearch 3.x has a larger community, a built-in security plugin and hybrid
search, but no dictionary tagger and a heavier footprint. Solr 9.x would have
meant a second port within two years.

## Consequences

Nothing removed in Solr 10 is used: no `<lib>`, no
`ManagedSynonymFilterFactory` (synonyms come from packs and expand at query
time), no language-specific response writers, no `ExternalFileField`. The
Tagger dictionary collection is single-sharded.
