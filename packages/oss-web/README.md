# oss-web

The Semascope browser UI: React 19, TypeScript, Vite, TanStack Query and
Router, Tailwind with shadcn/ui, Cytoscape.js for the graph, MapLibre GL for
the map, ECharts for timelines, PDF.js for previews. Scaffolded in Phase 1;
this package is a placeholder so the Dockerfile's web stage resolves.
